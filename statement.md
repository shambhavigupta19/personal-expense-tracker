# Personal Expense Tracker

## 1. Problem Statement

Managing daily expenses manually can make it difficult to track spending and stay within a monthly budget. A simple system is needed to record expenses and provide basic spending information.

## 2. Scope of the Project

The project provides a command-line system for recording and managing personal expenses. Users can add, view, search, and delete expenses, set and check a monthly budget, and generate basic spending reports.

The project is limited to in-memory data storage and does not include databases, user accounts, or online services.

## 3. Target Users

The application is designed for students and individuals who want a simple way to track their daily expenses and monthly budget.

## 4. High-Level Features

* Add and manage expenses
* View all recorded expenses
* Search expenses by category
* Delete expenses
* Set a monthly budget
* Check budget status
* Generate spending reports
* View available expense categories
* Validate user input
